# 社区发帖规范及注意事项

欢迎来玩。这里是一个不端着、不审判的彩虹社区——发帖前花两分钟看完，后面会轻松很多。

## 一、先找对地方

| 版块 | 分类 | 适合发什么 |
|---|---|---|
| 交友 | 征友 / 同城 / 兴趣 / 闲聊 | 找人、约饭、组局、找人一起玩 |
| 视频 | 原创 / 搬运 / 直播回放 / 推荐 | 视频与直播相关 |
| 小说 | 都市 / 校园 / 古代 / 奇幻 / 悬疑 / 短篇 / 搬运 | 原创或转载的小说；转载请选「搬运」 |
| 会员中心 | 权益说明 / 积分兑换 / 活动 / 意见反馈 | 等级、积分、功能问题、活动 |
| 公告 | 站务公告 / 功能更新 | 站点通知（一般只读） |

- 标题写清楚（5–120 字），正文支持 Markdown：`**加粗**`、`# 标题`、`- 列表`、代码块都行
- 一帖发一处，别为了曝光重复发
- 草稿会自动存在本机「草稿箱」，7 天内回来还能接着写

## 二、这些是底线（碰到直接处理，不提醒）

1. **未成年人**：本站仅限 18 岁以上。任何涉及未成年人的性内容、图片、引诱，一律删除并封号。
2. **非自愿与偷拍**：胁迫、下药、迷奸、偷拍、报复性曝光的内容，一律删除并封号。
3. **隐私**：不要公开他人照片、聊天记录、手机号、微信号、住址、单位、家人信息。贴合影要本人同意；发照片前检查有没有门牌、定位、工牌。
4. **违法交易**：性交易、代孕中介、毒品与管制药物、管制器具、个人信息买卖、偷拍设备。
5. **广告与诈骗**：引流、卖号、带单、投资理财、博彩、"交友中介"、收费入群、代收转账。交友帖不要留收款方式。
6. **挂人与骚扰**：有纠纷走举报，不要开帖对线；不得人肉、持续骚扰、恶意曝光。
7. **歧视与攻击**：不要拿地域、体型、年龄、职业、言行举止说事；**HIV 状态不是攻击理由**，拿这个羞辱人会被封号。

## 三、分版细则

**交友**：写清你想找什么、不找什么（比如"只聊天不见面"也请写明）。不代发他人信息；约见面前先确认安全。

**视频**：原创优先。搬运注明来源，去掉别人的水印和联系方式再发。偷拍、未经同意的性爱视频、未成年人相关的，一律删除。

**小说**：原创和搬运都欢迎，搬运一律选「搬运」分类。
- 站内「搬运」内容只作存档，**版权归原作者**；原作者或权利人可以在帖内举报，我们会删除。
- 读者讨论请走主题页的「读者讨论」，不要在章节正文里刷楼。
- 求资源、求后续请到读者讨论，不要反复顶帖。

**会员中心**：等级、积分、权限问题发这里。反馈 bug 请写清设备、浏览器和复现步骤，方便我们定位。

## 四、互动礼仪

- 可以不同意，但讲道理，别扣帽子、别阴阳怪气
- 私信同样受本规范约束；对方说不聊了就别追
- 评分（支持 / 反对）请带上理由，恶意刷分、抱团点踩会被处理
- 健康话题（检测、PrEP/PEP、用药）请以专业医生和疾控为准，**不要在站内求医问药或推荐来路不明的药**

## 五、审核与权限

- 命中敏感词的帖子会进**待审**，人工过一遍就放行，不是针对你
- 新账号有每日发帖/回帖上限、附件大小限制；等级升上去会逐步放宽（等级见「设置」页）
- 外链和附件按等级开放，等级不够的链接会转待审
- 小号刷帖、机器发帖、复制粘贴灌水：删帖 + 禁言

## 六、举报与处理

- 每个帖子右上角有「举报」，资料页和私信也可以举报
- 处理阶梯：提醒 / 删帖 → 警告 → 禁言 → 封号；严重违规直接封号
- 举报人信息不会公开；被误判可以发邮件申诉，我们会复核

## 七、新手上路小抄

- 发帖：首页「+ 发个帖子」、版块页「发新帖」，手机端右下角「发新帖」
- 收藏和追更：主题页点「☆ 收藏 / ☆ 追更」，有更新会通知你
- 想改内容：自己发的帖子可以编辑，版主也会协助
- 不知道发哪：随便找个合适版块发，版主会帮忙挪
